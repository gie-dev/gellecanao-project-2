# Kabankalan Catholic College, Inc. – Landing Page (Project 2)

Single-page responsive landing page built from the **Mentor** Bootstrap 5 template.

**Stack:** HTML5, CSS3, Bootstrap 5.3, Bootstrap Icons, AOS, GLightbox, Swiper.

## Run locally
Open the folder in VS Code, install the **Live Server** extension, right-click `index.html` → *Open with Live Server*.

## Content to replace (search the code for `REPLACE` and `Placeholder`)
- Mission, vision, core values, history, school introduction
- Program names and descriptions (Academics)
- Enrollment information, address, phone, email, Facebook link, map pin
- Sample news cards and all images in `assets/img/hero-bg.jpg`, `about.jpg`, `programs/`, `campus/`, `events/`

## Verified from the official seal
Name, location (Kabankalan City, Negros Occidental), year 1927, motto "Teach ye all nations" (Matthew 28:19).
